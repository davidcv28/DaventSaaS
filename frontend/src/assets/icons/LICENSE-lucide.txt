Lucide Icons
============

The SVG files in this directory are unmodified copies of icons from the
Lucide icon set, bundled locally (no CDN) so the AI design blocks can use them.

wrapper attributes are set for this app (stroke="currentColor",
stroke-width="1.75", no fixed width/height, no fill).
